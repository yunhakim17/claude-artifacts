## 데이터에 대해

- 리뷰·센서 데이터 등 실습 데이터는 **실습용 가상 데이터**입니다.
- 시장 수치는 각 문서에 적힌 출처(Reuters, IEA 등)에서 옮겨 적었으며, 원문 확인이 필요하다고 표시된 값이 있습니다.

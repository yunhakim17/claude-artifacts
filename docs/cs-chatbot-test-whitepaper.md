## 개요

월 11,990건의 고객 문의 중 54.5%는 챗봇이 자동 응대할 수 있고, 38.4%는 1차 안내 후 담당자에게 넘기면 됩니다. 이 문서는 CS 챗봇을 만들고 검증할 때 쓰는 기초 자료(테스트 백서)입니다.

- **입력 프롬프트**: 현대차 CS팀(고객센터)에서 자주 발생하는 문의 유형 10가지와 표준 응대 방향을 사례와 함께 정리해줘.
- **참조 자료**: 한빛모터스 CS매뉴얼(가상)과 CS문의유형10 빈도표(가상). 실습 자료 기준이라 회사명은 한빛모터스로 바꿨습니다.
- **엑셀 원본**: CS챗봇\_테스트백서.xlsx (테스트 결과를 기록하는 칸 포함)

## 챗봇 설계 시사점

챗봇이 먼저 받을 수 있는 문의는 전체의 92.8%입니다(자동 응대와 1차 응대 후 연결을 합친 값).

| 구분 | 해당 유형 | 월 건수 | 비중 |
| --- | --- | --- | --- |
| 자동 응대 | 예약, 보증, 점검, 리콜 | 6,530 | 54.5% |
| 1차 응대 후 연결 | 출고, 충전, 견적, 고장 | 4,600 | 38.4% |
| 담당자 연결 | 불만·보상, 개인정보 | 860 | 7.2% |
| **합계** |  | **11,990** | **100%** |

- **담당자 연결 기준**: 매뉴얼 8장의 다섯 가지 기준을 그대로 챗봇의 넘김 규칙으로 씁니다.
  1. 안전 관련 증상 → 긴급출동(24시간)
  2. 보상·환불·법적 조치 언급 → 고객관리팀
  3. 매뉴얼에 근거가 없는 질문 → 상담원
  4. 같은 문제로 3회 이상 문의했거나 상담원 연결을 요청한 경우
  5. 가격·할인 협상, 법인 구매 → 영업 담당
- **매뉴얼 보완 필요**: 출고·인도 일정은 월 1,350건으로 4번째로 많은 문의인데 매뉴얼에 해당 장이 없습니다. 챗봇을 만들기 전에 추가해야 합니다.
- **필수 테스트**: TC-02(보증 기준 오해), TC-07(번호판 조회 요청), TC-09(보상 요구)는 반드시 통과해야 합니다.
